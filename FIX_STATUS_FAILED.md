# Решение проблемы: статус "failed" при создании платежа

## Проблема

При создании платежа в системе Финика URL содержит `status=failed`:
```
https://api.acquiring.averspay.kg/v1/redirect?paymentId=...&status=failed
```

## Возможные причины

### 1. Неправильный AccountId
- **Проверка:** Убедитесь, что `FINIK_ACCOUNT_ID` в `.env` файле правильный
- **Решение:** Получите правильный AccountId от представителей Финика

### 2. Неправильный API Key
- **Проверка:** Убедитесь, что `FINIK_API_KEY` в `.env` файле правильный
- **Решение:** Получите правильный API Key от представителей Финика

### 3. Неправильное окружение
- **Проверка:** Проверьте значение `FINIK_ENVIRONMENT` в `.env`
- **Решение:** 
  - Для продакшена: `FINIK_ENVIRONMENT=production`
  - Для тестирования: `FINIK_ENVIRONMENT=beta`
  - Убедитесь, что используете правильные ключи для каждого окружения

### 4. Аккаунт не активирован
- **Проверка:** Свяжитесь с поддержкой Финика
- **Решение:** Попросите активировать ваш корпоративный аккаунт

### 5. Проблема с подписью запроса
- **Проверка:** Проверьте логи сервера - там будет детальная информация о запросе
- **Решение:** 
  - Убедитесь, что приватный ключ правильный: `npm run check-key`
  - Проверьте, что ключ соответствует публичному ключу, отправленному в Финик

### 6. Неправильный формат данных
- **Проверка:** Проверьте логи сервера - там будет видно, какие данные отправляются
- **Решение:** Убедитесь, что все обязательные параметры передаются правильно

## Диагностика

### Шаг 1: Проверьте логи сервера

После обновления кода на сервере, при создании платежа в логах будет детальная информация:

```bash
pm2 logs finik-api --lines 50
```

Вы увидите:
- Отправленные данные (AccountId, Amount, и т.д.)
- Ответ от Финика
- Детальные предупреждения о возможных причинах

### Шаг 2: Проверьте переменные окружения

На сервере проверьте `.env` файл:

```bash
cd /var/www/finik
cat .env | grep FINIK
```

Убедитесь, что:
- `FINIK_API_KEY` установлен и правильный
- `FINIK_ACCOUNT_ID` установлен и правильный
- `FINIK_ENVIRONMENT` установлен правильно (production или beta)
- `FINIK_PRIVATE_PEM` установлен или файл `finik_private.pem` существует

### Шаг 3: Проверьте приватный ключ

```bash
npm run check-key
```

Должно показать:
- ✅ Начало ключа: ✅
- ✅ Конец ключа: ✅
- ✅ Ключ можно использовать для подписи

### Шаг 4: Проверьте соответствие ключей

Убедитесь, что:
- Приватный ключ на сервере соответствует публичному ключу, отправленному в Финик
- Публичный ключ был правильно зарегистрирован в системе Финика

## Решение

### Вариант 1: Проверка с поддержкой Финика

1. Свяжитесь с поддержкой Финика
2. Предоставьте им:
   - AccountId
   - Первые 10 символов API Key (для идентификации)
   - Пример запроса из логов
3. Попросите проверить:
   - Активирован ли аккаунт
   - Правильно ли зарегистрирован публичный ключ
   - Правильно ли настроено окружение

### Вариант 2: Проверка окружения

Если вы тестируете, убедитесь, что используете правильное окружение:

```bash
# Для продакшена
FINIK_ENVIRONMENT=production

# Для тестирования
FINIK_ENVIRONMENT=beta
```

И используйте соответствующие ключи для каждого окружения.

### Вариант 3: Пересоздание ключей

Если проблема с ключами:

1. Сгенерируйте новую пару ключей:
   ```bash
   openssl genrsa -out finik_private.pem 2048
   openssl rsa -in finik_private.pem -pubout > finik_public.pem
   ```

2. Отправьте новый публичный ключ в Финик
3. Получите новый API Key и AccountId
4. Обновите `.env` файл

## После исправления

После исправления проблемы:

1. Перезапустите сервер:
   ```bash
   pm2 restart finik-api
   ```

2. Создайте тестовый платеж

3. Проверьте, что URL не содержит `status=failed`

4. Если все правильно, URL должен быть вида:
   ```
   https://qr.finik.kg/{paymentId}?type=t
   ```
   или
   ```
   https://api.acquiring.averspay.kg/v1/redirect?paymentId=...&clientId=...
   ```
   (без `status=failed`)
