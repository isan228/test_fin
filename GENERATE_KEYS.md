# Генерация ключей для Finik

## Быстрый старт

### 1. Сгенерируйте пару ключей

Запустите команду:

```bash
npm run generate-keys
```

Или напрямую:

```bash
node utils/generateKeys.js
```

Это создаст два файла:
- **privat1** - приватный ключ (храните в секрете!)
- **publ1** - публичный ключ (отправьте в Finik)

### 2. Отправьте публичный ключ в Finik

Откройте файл `publ1` и скопируйте его содержимое. Отправьте этот ключ в поддержку Finik для получения:
- API ключа (`FINIK_API_KEY`)
- Account ID (`FINIK_ACCOUNT_ID`)

### 3. Добавьте credentials в .env

После получения данных от Finik, добавьте в файл `.env`:

```env
FINIK_API_KEY=ваш_api_ключ_от_финика
FINIK_ACCOUNT_ID=ваш_account_id_от_финика
FINIK_ENVIRONMENT=production
```

**Важно:** Приватный ключ теперь читается из файла `privat1`, не нужно добавлять `FINIK_PRIVATE_PEM` в `.env`!

## Альтернативный способ: извлечение публичного ключа

Если у вас уже есть приватный ключ, можно извлечь из него публичный:

```bash
npm run extract-public-key
```

Или:

```bash
node utils/extractPublicKey.js
```

Это извлечет публичный ключ из файла `privat1` и сохранит его в `publ1`.

## Безопасность

⚠️ **ВАЖНО:**
- Файлы `privat1` и `publ1` добавлены в `.gitignore` - они НЕ будут закоммичены в Git
- Никогда не коммитьте приватные ключи в репозиторий
- Храните `privat1` в безопасности
- Не передавайте `privat1` третьим лицам

## Проверка ключей

После генерации можно проверить ключи:

```bash
npm run check-key
```

Это проверит, что приватный ключ в файле `privat1` валиден и может быть использован.

## Структура файлов

```
finik/
├── privat1          # Приватный ключ (НЕ коммитить!)
├── publ1            # Публичный ключ (можно коммитить, но не обязательно)
├── .env             # API ключ и Account ID от Finik
└── utils/
    ├── generateKeys.js      # Генерация новой пары ключей
    ├── extractPublicKey.js  # Извлечение публичного из приватного
    └── loadPrivateKey.js    # Загрузка приватного ключа из файла
```

## Миграция со старого способа

Если вы раньше использовали `FINIK_PRIVATE_PEM` в `.env`:

1. Извлеките ключ из `.env` или создайте новый:
   ```bash
   npm run generate-keys
   ```

2. Скопируйте содержимое `FINIK_PRIVATE_PEM` в файл `privat1` (если хотите использовать старый ключ)

3. Удалите `FINIK_PRIVATE_PEM` из `.env` (опционально, файл имеет приоритет)

4. Перезапустите сервер

## Troubleshooting

### Ошибка: "Приватный ключ не найден"

Убедитесь, что файл `privat1` существует в корне проекта.

### Ошибка при генерации ключей

Проверьте права на запись в директорию проекта.

### Ключ не работает с Finik

1. Убедитесь, что отправили правильный публичный ключ (из файла `publ1`)
2. Проверьте, что публичный ключ зарегистрирован в системе Finik
3. Убедитесь, что используете правильный API ключ и Account ID для вашего окружения
