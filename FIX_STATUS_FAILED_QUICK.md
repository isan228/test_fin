# Быстрое исправление: status=failed в paymentUrl

## Проблема

При создании платежа получаете:
```json
{
  "success": true,
  "paymentUrl": "https://api.acquiring.averspay.kg/v1/redirect?paymentId=...&status=failed"
}
```

## Быстрая диагностика

### Шаг 1: Запустите диагностику

```bash
npm run diagnose
```

Этот скрипт проверит:
- ✅ Все переменные окружения
- ✅ Приватный ключ
- ✅ Окружение (production/beta)

### Шаг 2: Проверьте логи сервера

```bash
pm2 logs finik-api --lines 100
```

Ищите строки:
```
❌ ⚠️  ⚠️  ⚠️  ПЛАТЕЖ СОЗДАН СО СТАТУСОМ FAILED ⚠️  ⚠️  ⚠️
```

Там будет детальная информация о проблеме.

## Наиболее частые причины

### 1. Неправильный AccountId (90% случаев)

**Проверка:**
```bash
cd /var/www/finik
cat .env | grep FINIK_ACCOUNT_ID
```

**Решение:** Получите правильный AccountId от представителей Финика.

### 2. Неправильный API Key

**Проверка:**
```bash
cat .env | grep FINIK_API_KEY
```

**Решение:** Получите правильный API Key от представителей Финика.

### 3. Неправильное окружение

**Проверка:**
```bash
cat .env | grep FINIK_ENVIRONMENT
```

**Решение:**
- Если используете тестовые данные: `FINIK_ENVIRONMENT=beta`
- Если используете продакшн данные: `FINIK_ENVIRONMENT=production`

### 4. Аккаунт не активирован

**Решение:** Свяжитесь с поддержкой Финика и попросите активировать аккаунт.

## Что делать

1. **Запустите диагностику:**
   ```bash
   npm run diagnose
   ```

2. **Проверьте переменные окружения:**
   ```bash
   cat .env | grep FINIK
   ```

3. **Проверьте логи:**
   ```bash
   pm2 logs finik-api --lines 100
   ```

4. **Свяжитесь с поддержкой Финика:**
   - Предоставьте AccountId
   - Предоставьте первые 10 символов API Key
   - Попросите проверить активацию аккаунта

## После исправления

1. Обновите `.env` файл
2. Перезапустите сервер:
   ```bash
   pm2 restart finik-api
   ```
3. Создайте тестовый платеж
4. Проверьте, что URL **НЕ содержит** `status=failed`

## Правильный URL должен быть:

```
https://api.acquiring.averspay.kg/v1/redirect?paymentId=...&clientId=...
```

**БЕЗ** `&status=failed` в конце!
