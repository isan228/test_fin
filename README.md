# Финик - Управление API ключами

Система управления API ключами для интеграции с платежной системой Финик.

## 🚀 Технологии

- **Node.js** - серверная платформа
- **Express** - веб-фреймворк
- **PostgreSQL** - база данных
- **Sequelize** - ORM для работы с БД
- **HTML/CSS/JavaScript** - фронтенд интерфейс

## 📋 Требования

- Node.js 14+
- PostgreSQL 12+
- npm или yarn

## 🔧 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd finik
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
```bash
cp .env.example .env
```

Отредактируйте `.env` файл и укажите:
- Данные для подключения к PostgreSQL
- API ключи Финика (если есть)
- IP адрес сервера (2.56.179.126)

4. Создайте базу данных PostgreSQL:
```bash
createdb finik_db
```

5. Запустите миграции:
```bash
npm run migrate
```

Или используйте автоматическую синхронизацию (таблицы создадутся при первом запуске).

6. Запустите сервер:
```bash
# Режим разработки
npm run dev

# Продакшн
npm start
```

## 📡 API Endpoints

### API Ключи

- `GET /api/keys` - Получить все ключи
- `GET /api/keys/:id` - Получить ключ по ID
- `POST /api/keys` - Создать новый ключ
- `POST /api/keys/generate` - Сгенерировать пару ключей (открытый/закрытый)
- `POST /api/keys/create-finik` - Создать API ключ от Финика (с отправкой запроса в Финик)
- `PUT /api/keys/:id` - Обновить ключ
- `DELETE /api/keys/:id` - Удалить ключ

### Платежи

- `GET /api/payments` - Получить все платежи
- `GET /api/payments/:id` - Получить платеж по ID
- `POST /api/payments/test` - Создать тестовый платеж

### Callback

- `POST /callback/finik` - Обработка callback от Финика
- `GET /callback/finik` - Проверка статуса платежа

## 🔑 Создание API ключа

### Генерация пары ключей

Система позволяет автоматически генерировать пару RSA ключей (открытый/закрытый):

1. Перейдите на страницу **Генерация ключей** (`/generate-keys.html`)
2. Нажмите "Сгенерировать ключи" - система создаст пару ключей
3. Скопируйте открытый и закрытый ключи

### Создание API ключа от Финика

Для создания API ключа от Финика нужны:
- **Открытый ключ (Public Key)** - сгенерированный публичный ключ
- **Закрытый ключ (Private Key)** - сгенерированный приватный ключ
- **Callback URL** - URL для получения callback от Финика (например: `http://2.56.179.126:3000/callback/finik`)

Эти ключи можно создать через веб-интерфейс на странице генерации ключей или через API.

## 📝 Структура базы данных

### Таблица `api_keys`
- `id` - ID ключа
- `name` - Название ключа
- `publicKey` - Открытый ключ (RSA)
- `privateKey` - Закрытый ключ (RSA)
- `callbackUrl` - URL для callback от Финика
- `finikApiKey` - API ключ, полученный от Финика
- `isActive` - Активен ли ключ
- `description` - Описание
- `createdAt`, `updatedAt` - Временные метки

### Таблица `payments`
- `id` - ID записи
- `apiKeyId` - Связь с API ключом
- `paymentId` - ID платежа от Финика
- `amount` - Сумма платежа
- `currency` - Валюта
- `status` - Статус (pending, success, failed, cancelled)
- `callbackData` - Данные из callback (JSON)
- `createdAt`, `updatedAt` - Временные метки

## 📦 Деплой на сервер

1. Загрузите код на сервер (через Git или SCP)
2. Установите зависимости: `npm install`
3. Настройте `.env` файл с правильными данными
4. Убедитесь, что PostgreSQL запущен и доступен
5. Запустите миграции: `npm run migrate`
6. Запустите сервер: `npm start`

Для постоянной работы используйте PM2:
```bash
npm install -g pm2
pm2 start server.js --name finik-api
pm2 save
pm2 startup
```
