# Исправление ошибки status=failed в paymentUrl

## Проблема

Платеж создается успешно, но в URL возвращается `status=failed`:
```json
{
  "success": false,
  "paymentUrl": "https://api.acquiring.averspay.kg/v1/redirect?paymentId=...&status=failed",
  "error": "Платеж отклонен Фиником (status=failed)"
}
```

## Что это означает

✅ **Хорошие новости:**
- Подпись правильная (иначе была бы ошибка 401)
- Аккаунт активен (иначе была бы ошибка 403)
- Запрос дошел до Финика

❌ **Проблема:**
- Финик отклонил платеж из-за неправильных данных или настроек

## Возможные причины

### 1. Неправильный AccountId (наиболее вероятно)

**Проверка:**
```bash
cd /var/www/finik
cat .env | grep FINIK_ACCOUNT_ID
```

**Решение:**
- Убедитесь, что AccountId правильный для **production** окружения
- AccountId для production может отличаться от beta
- Свяжитесь с поддержкой Финика для проверки правильности AccountId

### 2. Неправильный API Key

**Проверка:**
```bash
cat .env | grep FINIK_API_KEY
```

**Решение:**
- Убедитесь, что API Key правильный для **production** окружения
- API Key для production может отличаться от beta
- Свяжитесь с поддержкой Финика для проверки правильности API Key

### 3. Неправильное окружение

**Проверка:**
```bash
cat .env | grep FINIK_ENVIRONMENT
```

**Решение:**
- Для production: `FINIK_ENVIRONMENT=production`
- Для beta: `FINIK_ENVIRONMENT=beta`
- Убедитесь, что используете правильное окружение для ваших credentials

### 4. Аккаунт не полностью настроен

**Возможные проблемы:**
- Аккаунт создан, но не полностью активирован
- Не все настройки аккаунта завершены
- Ограничения на аккаунте (лимиты, разрешения)

**Решение:**
- Свяжитесь с поддержкой Финика
- Попросите проверить статус аккаунта
- Убедитесь, что аккаунт полностью настроен и готов к приему платежей

### 5. Неправильные параметры платежа

**Проверка в логах:**
```bash
pm2 logs finik-api --lines 200 | grep -A 50 "Request Body"
```

**Что проверить:**
- `merchantCategoryCode` - должен быть правильным (обычно "0742")
- `name_en` - должно быть на английском
- `webhookUrl` - должен быть доступен из интернета
- `redirectUrl` - должен быть правильным URL

## Диагностика

### Шаг 1: Проверьте логи сервера

```bash
pm2 logs finik-api --lines 300 | grep -A 100 "ПЛАТЕЖ СОЗДАН СО СТАТУСОМ FAILED"
```

В логах будет детальная информация:
- AccountId, который используется
- API Key (первые 10 символов)
- Окружение
- Все параметры запроса

### Шаг 2: Проверьте переменные окружения

```bash
cd /var/www/finik
cat .env | grep FINIK
```

Убедитесь:
- `FINIK_ENVIRONMENT=production` (или `beta`)
- `FINIK_API_KEY` правильный для выбранного окружения
- `FINIK_ACCOUNT_ID` правильный для выбранного окружения

### Шаг 3: Проверьте данные в логах

В логах найдите строки:
```
❌ ⚠️  ⚠️  ⚠️  ПЛАТЕЖ СОЗДАН СО СТАТУСОМ FAILED ⚠️  ⚠️  ⚠️
```

Там будет список:
- AccountId, который был отправлен
- API Key (первые 10 символов)
- Окружение
- Все параметры запроса

## Что отправить в поддержку Финика

```
Окружение: PRODUCTION (или BETA)
AccountId: <ваш_account_id_из_логов>
API Key: <первые_10_символов_из_логов>

Проблема: Платеж создается успешно, но в paymentUrl возвращается status=failed.

Детали запроса (из логов):
- Amount: <сумма>
- MerchantCategoryCode: <код>
- Name (en): <название>
- WebhookUrl: <url>
- RedirectUrl: <url>

Прошу проверить:
1. Правильность AccountId для production окружения
2. Правильность API Key для production окружения
3. Полную активацию и настройку аккаунта
4. Возможные ограничения на аккаунте
```

## После исправления

1. Обновите credentials в `.env` на сервере
2. Перезапустите сервер: `pm2 restart finik-api`
3. Выполните тестовый запрос снова
4. Проверьте, что `status=failed` больше не появляется

## Важно

Если вы видите `status=failed`, это означает, что:
- ✅ Код работает правильно
- ✅ Подпись правильная
- ✅ Аккаунт активен
- ❌ Но данные платежа или настройки аккаунта неправильные

Свяжитесь с поддержкой Финика с информацией из логов - они помогут исправить проблему.
