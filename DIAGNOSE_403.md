# Диагностика ошибки 403 Forbidden

## Срочные шаги для диагностики

### Шаг 1: Обновите код на сервере

```bash
cd /var/www/finik
git pull
pm2 restart finik-api
```

### Шаг 2: Проверьте логи после запроса

Выполните запрос снова:
```bash
curl -X POST http://2.56.179.126:3000/api/finik/payment \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 1,
    "redirectUrl": "http://2.56.179.126:3000/success",
    "webhookUrl": "http://2.56.179.126:3000/webhooks/finik",
    "merchantCategoryCode": "0742",
    "name_en": "Test Payment"
  }'
```

Затем сразу проверьте логи:
```bash
pm2 logs finik-api --lines 200
```

### Шаг 3: Найдите в логах

Ищите следующие строки:
- `📤 Создание платежа в Финике:` - показывает все параметры запроса
- `Canonical String (для подписи):` - показывает каноническую строку для подписи
- `❌ Finik API error:` - показывает детальную информацию об ошибке
- `⚠️  403 Forbidden - возможные причины:` - показывает список возможных причин

### Шаг 4: Проверьте переменные окружения

```bash
cd /var/www/finik
cat .env | grep FINIK
```

Убедитесь, что:
- `FINIK_API_KEY` установлен и правильный
- `FINIK_ACCOUNT_ID` установлен и правильный
- `FINIK_ENVIRONMENT` установлен правильно (production или beta)
- `FINIK_API_PATH` установлен (или не установлен, тогда используется `/payment` по умолчанию)

### Шаг 5: Проверьте каноническую строку

В логах найдите строку:
```
Canonical String (для подписи):
───────────────────────────────────────────────────
post
/payment
host:api.acquiring.averspay.kg&x-api-key:...&x-api-timestamp:...
{"Amount":1,...}
───────────────────────────────────────────────────
```

**ВАЖНО:** Проверьте порядок заголовков:
- Должно быть: `host:...&x-api-key:...&x-api-timestamp:...`
- НЕ должно быть: `x-api-key:...&x-api-timestamp:...&host:...`

Если порядок неправильный, код на сервере не обновлен!

## Возможные причины 403 Forbidden

1. **Код на сервере не обновлен** - выполните `git pull && pm2 restart finik-api`
2. **Неправильный путь API** - проверьте `FINIK_API_PATH` в `.env`
3. **Неправильная подпись** - проверьте каноническую строку в логах
4. **Неправильный API Key** - проверьте `FINIK_API_KEY` в `.env`
5. **Неправильный AccountId** - проверьте `FINIK_ACCOUNT_ID` в `.env`
6. **Неправильное окружение** - проверьте `FINIK_ENVIRONMENT` (должно быть `production` или `beta`)
7. **Аккаунт не активирован** - свяжитесь с поддержкой Финика
8. **Публичный ключ не зарегистрирован** - отправьте публичный ключ в Финик

## Что отправить в поддержку Финика

Если проблема не решается, отправьте в поддержку Финика:

1. **AccountId:** (из `.env`)
2. **Первые 10 символов API Key:** (из логов)
3. **Окружение:** production или beta
4. **Каноническую строку:** (из логов)
5. **Полный URL запроса:** (из логов, строка `Full URL:`)
6. **Path:** (из логов, строка `Path:`)
