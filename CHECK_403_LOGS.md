# Проверка логов для диагностики 403 Forbidden

## Шаг 1: Проверьте логи PM2

На сервере выполните:

```bash
pm2 logs finik-api --lines 200
```

Ищите следующие строки после вашего запроса:

### 1. Информация о запросе:
- `📤 Создание платежа в Финике:`
- `Environment:` - должно быть `production` или `beta`
- `Base URL:` - URL API Финика
- `Path:` - путь API (должен быть `/v1/payment` или `/payment`)
- `AccountId:` - ваш AccountId
- `API Key (первые 10 символов):` - первые символы вашего API ключа

### 2. Каноническая строка:
- `Canonical String (для подписи):` - полная каноническая строка
- `Canonical String Parts:` - части канонической строки

### 3. Детали ошибки:
- `❌ Finik API error:`
- `⚠️  403 Forbidden - возможные причины:`
- Список возможных причин

## Шаг 2: Проверьте переменные окружения

```bash
cd /var/www/finik
cat .env | grep FINIK
```

Убедитесь, что:
- `FINIK_API_KEY` установлен и правильный
- `FINIK_ACCOUNT_ID` установлен и правильный
- `FINIK_ENVIRONMENT` установлен правильно (`production` или `beta`)
- `FINIK_API_PATH` установлен (если нужно, обычно `/v1/payment`)

## Шаг 3: Проверьте файл ключа

```bash
cd /var/www/finik
ls -la priv1.pem
cat priv1.pem | head -1
```

Должно показать:
- Файл существует
- Начинается с `-----BEGIN PRIVATE KEY-----` или `-----BEGIN RSA PRIVATE KEY-----`

## Шаг 4: Проверьте, что ключ загружается

В логах должна быть строка:
```
✅ Ключ загружен из файла: priv1.pem
```

Если её нет, проверьте права доступа:
```bash
chmod 600 priv1.pem
```

## Что делать дальше

После проверки логов, отправьте мне:
1. Строки из логов с `Environment:`, `AccountId:`, `API Key (первые 10 символов):`
2. Строку с `Path:` (какой путь используется)
3. Список возможных причин из логов

Это поможет точно определить проблему.
