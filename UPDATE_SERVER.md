# Обновление сервера после пуша в GitHub

## Быстрый процесс обновления

После того как вы запушили изменения в GitHub, на сервере выполните:

```bash
cd /var/www/finik
git pull
npm install  # только если были добавлены новые зависимости
pm2 restart finik-api
pm2 logs finik-api --lines 20  # проверьте логи
```

## Автосинхронизация БД

✅ **В тестовом окружении** (`NODE_ENV != production`) включена автосинхронизация БД.

При перезапуске сервера Sequelize автоматически:
- Создаст новые таблицы, если их нет
- Добавит недостающие колонки в существующие таблицы
- Обновит типы данных (если безопасно)

В логах вы увидите:
```
✅ Подключение к базе данных установлено успешно.
🔄 Синхронизация БД с опциями: { alter: true }
✅ Модели синхронизированы с базой данных.
```

## Что происходит при обновлении

1. **Git pull** - получаете последние изменения из GitHub
2. **npm install** - устанавливаете новые зависимости (если есть)
3. **pm2 restart** - перезапускаете сервер
4. **Автосинхронизация** - Sequelize автоматически обновляет схему БД

## Проверка после обновления

```bash
# Проверьте, что сервер работает
curl http://2.56.179.126:3000/api/keys

# Проверьте логи на ошибки
pm2 logs finik-api --lines 50
```

## Если что-то пошло не так

1. Проверьте логи: `pm2 logs finik-api`
2. Проверьте переменные окружения в `.env`
3. Убедитесь, что база данных доступна
4. Если нужно откатить изменения: `git reset --hard HEAD~1 && pm2 restart finik-api`

## Важно для продакшена

⚠️ В продакшене (`NODE_ENV=production`) автосинхронизация **отключена** для безопасности.
В продакшене используйте миграции: `npm run migrate`
