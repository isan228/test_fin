Информация:
Эта форма использует новый endpoint /api/finik/payment, который работает с переменными окружения.
Убедитесь, что в файле .env установлены: FINIK_API_KEY, FINIK_PRIVATE_PEM, FINIK_ACCOUNT_ID
Если включено, используется /api/finik/payment. Если выключено - старый способ через БД.
Выберите активный API ключ для тестирования (старый способ)
