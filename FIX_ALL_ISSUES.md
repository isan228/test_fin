# Исправление всех проблем из логов

## Проблемы в логах:

1. ❌ Ошибка синхронизации БД: `syntax error at or near "UNIQUE"`
2. ❌ Ошибка сохранения платежа: `Payment.apiKeyId cannot be null`
3. ❌ Ошибка подписи: `An invalid signature is provided`
4. ❌ Ошибка доступа: `Forbidden`

## Решение (по порядку):

### Шаг 1: Обновить код на сервере

```bash
cd /var/www/finik
git pull
npm install  # если были новые зависимости
```

### Шаг 2: Исправить ошибку синхронизации БД

Ошибка возникает из-за попытки добавить UNIQUE в ALTER COLUMN. Это уже исправлено в коде.

**Вариант 1: Отключить автосинхронизацию временно**

В `server.js` измените:
```javascript
const syncOptions = { alter: false }; // временно отключить
```

**Вариант 2: Запустить миграции**

```bash
npm run migrate
```

Это выполнит миграцию `20240101000005-add-unique-payment-id.js`, которая правильно добавит уникальное ограничение.

### Шаг 3: Перезапустить сервер

```bash
pm2 restart finik-api
pm2 logs finik-api --lines 50
```

### Шаг 4: Проверить исправления

После перезапуска:
- ✅ Ошибка `apiKeyId cannot be null` должна исчезнуть (исправлено в коде)
- ✅ Ошибка синхронизации БД должна исчезнуть (если запустили миграции)
- ✅ Окружение должно нормализоваться: `BETA` → `beta`

### Шаг 5: Проверить подпись

Если все еще получаете `An invalid signature is provided`:

1. **Проверьте окружение:**
   ```bash
   npm run diagnose
   ```
   Должно показать:
   ```
   Окружение (нормализовано): beta
   API URL: https://beta.api.acquiring.averspay.kg
   ```

2. **Проверьте приватный ключ:**
   ```bash
   npm run check-key
   ```

3. **Проверьте соответствие ключей:**
   - Убедитесь, что приватный ключ соответствует публичному ключу, отправленному в Финик
   - Убедитесь, что публичный ключ зарегистрирован в beta окружении Финика

4. **Проверьте логи:**
   ```bash
   pm2 logs finik-api --lines 100 | grep -i signature
   ```

### Шаг 6: Проверить credentials

Если получаете `Forbidden`:

1. **Проверьте AccountId:**
   ```bash
   cat .env | grep FINIK_ACCOUNT_ID
   ```
   Убедитесь, что это правильный AccountId для **beta** окружения.

2. **Проверьте API Key:**
   ```bash
   cat .env | grep FINIK_API_KEY
   ```
   Убедитесь, что это правильный API Key для **beta** окружения.

3. **Свяжитесь с поддержкой Финика:**
   - Предоставьте AccountId
   - Предоставьте первые 10 символов API Key
   - Попросите проверить активацию аккаунта в **beta** окружении
